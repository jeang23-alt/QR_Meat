🥩 큐미트 뒷다리살 프로틴 보울

  • 사용 부위: 돼지 뒷다리살 또는 안심 150g
  • 구성: 현미밥·잡곡밥 100g + 양상추 + 오이 + 토마토 + 삶은 달걀 반 개 + 저당 간장소스
뒷다리살을 얇게 썰어 간장·다진 마늘·후추·레몬즙에 10분 재운다.
팬에 센 불로 오래 볶지 말고, 중불에서 물 2~3스푼을 넣어 촉촉하게 익힌다.
밥과 채소 위에 올려 보울 형태로 제공한다.

🥗 마늘소스 뒷다리살 냉수육 샐러드

  • 사용 부위: 돼지 뒷다리살
  • 구성: 삶은 뒷다리살 + 오이 + 양배추 + 부추 + 파프리카 + 겨자 마늘소스

식힌 뒤 얇게 썰고 채소와 함께 담는다.

🍱 뒷다리살 소보로 도시락

  • 사용 부위: 돼지 뒷다리살 다짐육
  • 구성: 다짐육 + 두부 + 달걀 + 브로콜리 + 현미밥
팬에 고기·으깬 두부·간장·다진 마늘·후추를 넣고 수분을 날리듯 볶는다.
기름은 최소화하고, 밥 위에 소보로와 데친 브로콜리·달걀을 올린다.
💡 다짐육으로 쓰면 질김 문제가 거의 사라진다!

🌶️ 매콤 뒷다리살 고단백 덮밥

  • 사용 부위: 돼지 뒷다리살 얇은 불고기감 150g
  • 구성: 양파 + 대파 + 양배추 + 밥 100~150g
  • 양념: 고추장 0.5T·간장 1T·다진 마늘·고춧가루·후추·물 3T
뒷다리살을 최대한 얇게 썰고 양념에 10분 재운다.
팬에 양파·양배추를 먼저 볶아 수분을 만든 뒤 고기를 넣는다.
물을 조금 넣고 자작하게 익히면 질김이 줄어든다.
